Introduction
============

Documentation
-------------

The source of the documentation is available under the directory ``docs`` of
this repository. This documentation can be compiled for any commit as described
in the ``Makefile``.

The file format used for this documentation is `ReStructuredText
<https://en.wikipedia.org/wiki/ReStructuredText>`_. Thanks to the documentation 
generator `Sphinx
<https://en.wikipedia.org/wiki/Sphinx_(documentation_generator)>`_, the files
can be easily converted to a multitude of formats (such as an HTML website or a
PDF document).

If you are new to this simple format or Sphinx, you might find the following
resources useful:

* `Sphinx documentation about reStructuredText
  <https://www.sphinx-doc.org/en/master/usage/restructuredtext/index.html>`_
* `Cheat sheets for reStructuredText and Sphinx
  <https://sphinx-tutorial.readthedocs.io/cheatsheet/>`_
* `Style guide for NumPy-style docstrings
  <https://numpydoc.readthedocs.io/en/latest/format.html>`_
