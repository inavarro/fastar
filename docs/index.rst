Welcome to FASTAR
==================================

FASTAR is a new generation of evolutionary stellar population synthesis codes. It is rooted in our experience developing the `MILES
<https://research.iac.es/proyecto/miles/>`_ stellar population models but goes beyond the standard SSP approach, providing **continuous and differentiable model predictions**. Furthermore, the optimized `JAX <https://docs.jax.dev/en/latest/index.html>`_ implementation allows the synthesis on the fly of stochastic, **semi-resolved models**.

This documentation briefly describes the synthesis of SSP models using FASTAR as well as some of its main outputs and functionalities.
